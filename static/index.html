Set up the Go engine

Go Teacher analyses games with KataGo and shares its setup with KaTrain, a free Go program. Follow these steps once (about 15 minutes, mostly downloads); afterwards both programs use the same fast engine.

  1. Install KaTrain. Download KaTrain for macOS, drag it into /Applications and open it once. It works immediately with a small built-in engine; the next steps make it several times faster and stronger.
  2. Install KataGo with the Metal backend (uses the Apple GPU and Neural Engine). In Terminal: 
    brew install katago
katago version        # must print "Using Metal backend"
    If you do not have Homebrew, install it first from brew.sh.
  3. Download the latest network. On katagotraining.org/networks take the newest transformer network (name starting with b11c768h12nbt or newer) and save it as ~/.katago/default_model.bin.gz. Also download the human-style network b18c384nbt-humanv0.bin.gz from KataGo's releases (release v1.15.0 or later) as ~/.katago/default_human_model.bin.gz: it lets KaTrain play you at your own rank and lets Go Teacher tell you how typical each mistake is for your level.
  4. Tell KaTrain. In KaTrain open Settings → Engine and set: executable /opt/homebrew/bin/katago, model ~/.katago/default_model.bin.gz, human-like model ~/.katago/default_human_model.bin.gz. Leave the config field as it is unless you have your own. Save.
  5. Click Retry. Go Teacher reads KaTrain's engine settings and starts the same engine. The banner above turns green and shows "Metal backend".

Prefer not to use KaTrain? Enter the paths in Engine settings below instead; they take precedence over KaTrain's.
